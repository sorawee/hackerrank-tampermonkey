# hackerrank-tampermonkey

HackerRank is used in some classes for grading. Unfortunately, their recent UI makes the site become unusable. This Tampermonkey script makes the UI become usable again.

## Features

### Display running time for each test case in a submission view

![demo for running time display](/assets/images/demo-submission.png)

### Display detailed leaderboard

![demo for detailed leaderboard display](/assets/images/demo-leaderboard.png)

## Setup

1. Download a [Tampermonkey](https://www.tampermonkey.net/) extension. 
   The extension supports both Firefox and Chrome.
2. Navigate to https://github.com/sorawee/hackerrank-tampermonkey/raw/refs/heads/main/dist/hackerrank-extract.user.js
3. Tampermonkey should automatically prompt for the userscript installation. Install it.
